## Knowledge and evidence

MyZubster is building a knowledge layer where contributions can be identified, classified and reviewed.

Current evidence states include:

- `PERSONAL_PRACTICE`
- `OBSERVATION`
- `EXTERNAL_SOURCE`
- `PROTOCOL`

The goal is to preserve the path from a real-world observation to a testable project without representing unverified claims as facts.
